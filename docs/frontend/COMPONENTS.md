# Modular Component Library & UX Rules
## Enterprise Mini SOC Platform

### 1. Reusable Component Hierarchy
- **Shadcn Primitives:** Pure presentational components (`Button`, `Badge`, `Dialog`, `Card`, `Select`, `Table`).
- **Domain Components:** High-level container components bound to Zustand or TanStack Query (`AlertTable`, `IncidentKanban`, `SOARApprovalModal`).
- **Dark Mode Standard:** Dark Slate background (`#0F172A`) with vibrant status accents (Red `#EF4444` for Critical, Amber `#F59E0B` for High, Emerald `#10B981` for Low).
